# BGP201-250408021-AhirTakip

BGP 201 Mobil Programlama dersi kapsamında React Native ve Expo kullanılarak geliştirilen **Ahır Takip Uygulaması**.

## Özellikler
- **Hayvan Listesi ve Detay:** Küpe numarası, tür, yaş ve sağlık durumuna göre hayvan takibi
- **Aşı Takibi:** Planlanan ve uygulanan aşıların takvim ve durum yönetimi
- **Raporlar:** Sürü ve sağlık durumuna ait özet istatistikler
- **Ayarlar:** Uygulama ve bildirim tercihleri

## Kurulum ve Çalıştırma
```bash
npm install
npx expo start
